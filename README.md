# Portofoliu — Nica Daniel

Website de prezentare profesională (Next.js + Tailwind CSS).

## Pornire

```bash
npm install
npm run dev
```

Deschide [http://localhost:3000](http://localhost:3000).

## Date personale

Completează placeholder-ele din `src/data/content.ts`:

- `email`
- `website`
- `linkedin`
- `github`
- proiectele din `projects`

## Structură

- `src/app` — layout-ul și pagina principală
- `src/components` — Hero, Despre, Abilități, Portofoliu, Contact, Footer
- `src/data/content.ts` — text, skill-uri și proiecte
